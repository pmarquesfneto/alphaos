## What It Is

AlphaOS consolidates macro signals, commodity data, positioning flows, alternative data, NLP intelligence, and AI-powered analysis into a single browser-based platform.

**No installation. No server. Open `index.html` in Chrome.**

## Modules

| Module | Pillar | Description |
|--------|--------|-------------|
| **Morning Briefing** | INTEL | AI-generated daily brief |
| **AlphaQuery** | INTEL | Conversational AI with full live market context |
| **Macro** | MARKET | Regime classifier, yield curves, CB hawkishness radar |
| **Flows** | MARKET | CFTC COT live positioning, ETF flows, EM capital flows |
| **Alt Data** | MARKET | Satellite storage, NDVI crop health, AIS vessels, ENSO |
| **NLP Intel** | MARKET | FinBERT CB scoring, supply chain stress, GDELT |
| **Commodities** | MARKET | 67 contracts · 14 exchanges · term structure · S&D |

## Quick Start

```bash
git clone https://github.com/pmarquesfneto/alphaos.git
cd alphaos
open index.html   # macOS
```

Or access live at: **https://pmarquesfneto.github.io/alphaos**
